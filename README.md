# Rating UI

A React component that lets users submit a star rating (1–5) with live feedback labels and a confirmation modal on submit.

## Features

- Interactive star rating with hover effects
- Feedback label per rating (Very Poor → Excellent)
- Modal confirmation displayed after submitting
- Supports multiple independent rating components on one page

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
```
